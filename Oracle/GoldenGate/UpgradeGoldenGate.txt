-------- here are some very high level steps for upgrading both source and target db/goldengate ---------
https://docs.oracle.com/en/middleware/goldengate/core/19.1/upgrading/upgrading-oracle-goldengate.pdf

1-Stop the source and target application that connect to the source and target database.
2-Stop all the extracts process either by using a bounded recovery checkpoint or by specifying the LOGEND option.
	-- the Recovery Checkpoint field shows the oldest time needed for recovery
	GGSCI> INFO EXTRACT EPDA, SHOWCH
	GGSCI> INFO EXTRACT EPDC, SHOWCH
	-- see open transactions gg is waiting on...go clean them up
	GGSCI> SEND EXTRACT EPDA, SHOWTRANS
	GGSCI> SEND EXTRACT EPDC, SHOWTRANS
	-- After you are finished cleaning up the long-running transactions, force a Bounded Recovery checkpoint
	GGSCI> SEND EXTRACT EPDA, BR BRCHECKPOINT IMMEDIATE
	GGSCI> SEND EXTRACT EPDC, BR BRCHECKPOINT IMMEDIATE
	-- get the current scn
	SQL> SELECT MIN(SCN) AS INSTANTIATION_SCN
	FROM (SELECT MIN(START_SCN) AS SCN
	FROM gv$transaction
	UNION ALL
	SELECT CURRENT_SCN
	FROM gv$database);
	-- compare to Recovery Checkpoint field
	GGSCI> INFO EXTRACT EPDA, SHOWCH
	GGSCI> INFO EXTRACT EPDC, SHOWCH
	-- verify there is no more redo data to capture ( You can skip this step, if you are using an integrated Extract)
	GGSCI> SEND EXTRACT EPDA LOGEND
	GGSCI> SEND EXTRACT EPDC LOGEND
	-- stop extracts
	GGSCI> STOP EXTRACT EPD*
	GGSCI> STOP EXTRACT DPD*
	-- remove ddl_trigger (If you are using integrated Extract, then you can skip this step)
3-Stop the Replicat processes and the managers.
4-Initiate the source and target database upgrade.

Extract upgrade considerations
	- If you are using trigger-based DDL support, you must rebuild the DDL objects
	- After completing the upgrade, run the UPGRADE HEARTBEATTABLE command to add extra columns for tables and lag views

Replicat upgrade considerations
	- All Replicat installations should be upgraded at the same time
	- When upgrading from the 18c release of Oracle GoldenGate to the 19c (19.1.0) release, ensure that you do not use the SOURCEDEF parameter in Replicat, otherwise the Replicat will abend. However, if the trail file format is pre-12.2, then SOURCEDEF is still required because no metadata exists in the trail file
